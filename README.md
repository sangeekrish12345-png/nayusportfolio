# Nayana K — Portfolio Website

A responsive portfolio built with HTML, CSS, and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open the `Nayana-Portfolio` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Personalise before publishing
- Replace the profile widget in `index.html` with a real photo when ready. Search for `profile-placeholder`.
- Check the email address in `index.html` and `js/script.js`.
- Replace the generic GitHub and LinkedIn URLs in the contact section with Nayana's exact profiles.
- Add real project repository/demo URLs where the page currently says `Add GitHub link` or `Project link coming soon`.
- Edit any skill or project details so they accurately reflect current experience.
- Add a resume PDF to `documents/` and add a download button if desired.

## Certificate images
The three supplied certificate photos are in `images/certificates/` and open in a larger modal when clicked.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `nayana-portfolio`.
2. Upload the contents of this folder (the `index.html` file should be at the repository root).
3. Open repository **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. Wait for GitHub Pages to publish the site.

Note: external Google Fonts need an internet connection; fallback fonts are included.
